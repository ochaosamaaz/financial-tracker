# Duit Tracker Pro 💰

Aplikasi pelacak keuangan pribadi berbasis web dengan fitur lengkap untuk mengelola pemasukan dan pengeluaran secara cerdas.

## Fitur Utama

### 1. Chat Input - Sekali Ketik, Langsung Tercatat
Cukup ketik pesan natural seperti:
- "lapor pemasukan 5.000.000 gaji bulanan"
- "pengeluaran 50.000 makan siang"
- "keluar 200rb bensin"
- "masuk 1jt freelance"

Sistem otomatis mengenali tipe, nominal, dan kategori transaksi.

### 2. Dashboard Rapi & Otomatis
- Ringkasan saldo, pemasukan, dan pengeluaran bulanan
- Update real-time setiap ada transaksi baru

### 3. Grafik, Insight Bulanan & Rasio 50/30/20
- **Grafik Donut** - Visualisasi kategori pengeluaran
- **Grafik Tren** - Perbandingan pemasukan vs pengeluaran 6 bulan terakhir
- **Rasio 50/30/20** - Analisis otomatis kebutuhan/keinginan/tabungan
- **Insight Cerdas** - Tips berdasarkan pola keuangan

### 4. Reminder Harian Otomatis
- Pengingat untuk mencatat keuangan setiap hari
- Notifikasi browser (jika diizinkan)
- Waktu reminder bisa diatur

### 5. Multi-User (Pasangan / Keluarga / Tim)
- Buat beberapa profil pengguna
- Data terpisah per user
- Mudah switch antar user

## Fitur Tambahan
- 🌙 Dark Mode / Light Mode
- 📊 Export data ke CSV
- 📱 Responsive (mobile-friendly)
- 💾 Data tersimpan di localStorage (tanpa server)
- 🏷️ Kategori lengkap dengan pengelompokan otomatis

## Cara Pakai

1. Buka `index.html` di browser
2. Tambahkan nama pengguna
3. Mulai catat transaksi via form atau chat!
